# App Store Connect Link Guide

Use the GitHub Pages URLs from this repository for App Store Connect.

Assuming GitHub Pages is enabled for this repository, the URLs will look like:

```text
https://AI-Scarlett.github.io/ichingdaily-public-links/
https://AI-Scarlett.github.io/ichingdaily-public-links/privacy.html
https://AI-Scarlett.github.io/ichingdaily-public-links/terms.html
https://AI-Scarlett.github.io/ichingdaily-public-links/support.html
https://AI-Scarlett.github.io/ichingdaily-public-links/subscriptions.html
https://AI-Scarlett.github.io/ichingdaily-public-links/ai-and-data.html
https://AI-Scarlett.github.io/ichingdaily-public-links/data-deletion.html
```

## App Store Connect Fields

- Privacy Policy URL: `privacy.html`
- Support URL: `support.html`
- Marketing URL: repository home page or app website, if available
- Terms of Use URL: `terms.html`
- Review Notes: explain that the app creates Chinese names locally and uses five-element associations only as cultural naming context

## Mac Availability

The app is planned as an iPhone/iPad app with Apple silicon Mac availability enabled through App Store Connect. It is not planned as a Mac Catalyst app.
